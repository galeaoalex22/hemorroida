# Hemorroida Sem Vergonha - página de vendas

Site estático preparado para GitHub e Vercel.

## Publicação na Vercel

1. Envie esta pasta para um repositório no GitHub.
2. Na Vercel, escolha **Add New > Project** e importe o repositório.
3. Use **Other** como framework e deixe o diretório de saída vazio.
4. Publique.

## Antes da publicação comercial

- Plano Básico configurado em R$ 23,90 com link próprio da Hotmart.
- Plano Mais Completo configurado em R$ 29,90 com link próprio da Hotmart.
- Quatro bônus definitivos com capas e descrições inseridos.
- Inserir o pixel quando o código for fornecido.
- Adicionar o botão flutuante do WhatsApp na próxima edição.
- Confirme as regras da garantia com a plataforma de pagamento.
